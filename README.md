# 🎲 MFU Board Game Borrowing App (Mobile Application)

## 💡 About the Project
This mobile application was developed to streamline the university's asset borrowing process. Realizing that the university provides board games for students—and being avid board game players ourselves—we tailored this application to make borrowing and returning board games effortless. 

The app features a real-time availability check, allowing students to instantly see if their favorite games are currently in stock before making a trip to the facility.
